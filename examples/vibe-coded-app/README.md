# vibe-coded-app (deliberately broken demo)

A small, **intentionally flawed** Next.js-style app that reproduces what AI agents commonly
ship when nothing checks their work: placeholder code, invented packages, a secret exposed to
the browser, an unvalidated route, swallowed errors, `any`, and no tests.

It exists for the README demo and the test suite. It is not meant to run.

```bash
npx realitygate audit examples/vibe-coded-app
```
